This folder contains the Numba implementation of binary_heuristic.py and branch_and_bound.py for solving the 0-1 Knapsack Problem. The code is optimized for performance using Numba's Just-In-Time (JIT) compilation, which allows for faster execution of numerical computations. Albeit slightly faster than the original code, the Numba implementation does not materially change the performance of the heuristic.
